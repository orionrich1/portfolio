# 포트폴리오 점검·수동 테스트 기록

> **수락 조건의 원본**은 `docs/PRODUCT_SPEC.md` 이다. 본 문서는 브라우저 점검·체크리스트 **기록용**이다.

## 문서 목적

단일 페이지 포트폴리오(`src/index.html`)에 대해 **로컬 개발 서버** 또는 **빌드 산출물**을 열고, 비주얼·링크·스크롤 동작을 확인한 결과를 남긴다.

---

## 1. 준비

| 항목 | 내용 |
|------|------|
| 의존성 설치 | 프로젝트 루트에서 `npm install` |
| 로컬 미리보기 | `npm run dev` → 기본 `http://localhost:5000` (포트는 `package.json`의 Parcel 옵션 기준) |
| 프로덕션 빌드 | `npm run build` — 오류 0건·산출물 생성 확인 |

---

## 2. 자동화 범위

이 저장소에는 **Gradle/JUnit** 등 서버 사이드 테스트 스위트가 없다. 품질은 **빌드 성공** + 아래 **수동 체크리스트**로 본다.

---

## 3. 수동 체크리스트 (브라우저)

**환경**: Chrome/Edge 최신 권장. 모바일은 DevTools 기기 모드 또는 실제 기기.

### 3.1 전역

- [ ] 첫 화면(히어로) 로딩 시 레이아웃 깨짐 없음
- [ ] 고정 헤더가 본문을 가리지 않고(필요 시 스크롤 보정) 앵커 이동이 자연스러움
- [ ] 콘솔에 **치명적** JS 오류 없음(경고만 있는지 구분)

### 3.2 내비게이션

- [ ] About / Projects / Skills / Journey 클릭 시 해당 섹션으로 스크롤
- [ ] 히어로 CTA(대표 프로젝트)가 `#projects`로 연결

### 3.3 프로젝트

- [ ] 각 프로젝트 GitHub 링크가 새 탭/보안 속성과 함께 열림
- [ ] Live Demo 링크 클릭 시 의도한 URL로 이동(외부 서버 다운은 별도 이슈)

### 3.4 스킬·애니메이션

- [ ] 스킬 섹션까지 스크롤 시 게이지/애니메이션이 의도대로(과도한 끊김·오류 없음)

### 3.5 푸터·연락

- [ ] mailto / tel / GitHub 링크 동작

### 3.6 공통 UI

- [ ] 맨 위로 버튼 표시/숨김·클릭 시 상단 이동
- [ ] 모달이 있는 화면에서 열기/닫기 정상

### 3.7 반응형

- [ ] `375px` / `768px` / `1280px` 부근에서 주요 섹션 읽기 가능, 가로 스크롤 이상 없음
